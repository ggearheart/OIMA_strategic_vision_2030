# OIMA Strategic Vision 2030

A landing page presenting the **Strategic Vision 2030** for the Office of
Information Management and Analysis (OIMA), California State Water Resources
Control Board.

## Structure

- `index.html` — the page content (vision, pillars, goals, roadmap)
- `styles.css` — styling

The content is placeholder/draft text meant to be edited to reflect OIMA's
actual strategic priorities.

## Local preview

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

The repo includes `.nojekyll` so it can be served directly via GitHub Pages
(Settings → Pages → deploy from `main`).
